# domn-film-screenplay-save-the-cat

> 独立技能仓库 · 来自 domn skills 集合（视频制作 域）

基于布莱克·斯奈德《救猫咪Ⅱ——经典电影剧本探秘》的剧本结构方法论。当用户提出写剧本、剧本结构、故事类型、节拍表、故事骨架、剧情推演、分集或整季大纲、提案评估、logline 需求时使用。把一句话提案匹配到 10 大故事题材之一，套用 15 拍结构表推演剧情骨架，并输出可写作的节拍表与大纲；适用于电影、剧集、动画、长片与分镜脚本的故事层设计，含 50 部影片节拍拆解语料与边界清单。仅适用超过 30 分钟的载体；≤30 分钟的科幻短片改用 domn-film-scifi-short-film。
