# 提案 → 题材 → 剧情推演：自动匹配引擎

> 这是本 skill 的"推理核心"。目标：拿到用户的一句提案（logline／梗概／创意／一句话点子），
> ① 判定主类型 + 副类型 → ② 生成该类型的三元素填空 → ③ 逐拍推演出剧情骨架 → ④ 用同类片校验。

---

> ⚠️ **先分流**：如果提案是**科幻**，先去 `06-chinese-hard-scifi.md` 做**塌架测试**（抽掉科幻构思故事是否塌架）。
> 塌（idea 主导）→ 用该文件的**认知疏离 5 拍（模型 B）**，不要用本文件的 10 题材。
> 不塌（构思只是背景）→ 回到本文件继续，但按该文件的**模型 A** 改造 15 拍。

## 第 0 步：把提案拆成 6 个信号

从用户提案中尽量抽取。**不要一上来就问一堆问题**——能推断的先推断，把推断写出来，只对真正决定类型的空缺发问（一轮最多 3 个）。

| # | 信号 | 提取方法 | 推断不出时的提问 |
|---|---|---|---|
| S1 | **主人公** | 谁在受苦？他无辜吗？ | "这个故事里，谁最痛苦？" |
| S2 | **引擎** | 让故事跑起来的那一下：外部事件 / 内部缺陷 / 另一个人 / 一个秘密 | "故事是从哪件事开始再也停不下来的？" |
| S3 | **谁会变** | 主人公变？观众变？另一个人变？ | "结尾改变的是谁？" |
| S4 | **对抗物** | 怪物 / 制度 / 另一个人 / 自己 / 命运 / 秘密 | "他最大的对手是什么？" |
| S5 | **空间** | 封闭的还是开放的？"房子"还是"道路"？ | "故事主要发生在哪儿——一个出不去的地儿，还是一条路上？" |
| S6 | **结局价值** | 幸存 / 得到 / 觉悟 / 在一起 / 付出代价 | "结束时他得到了什么？" |

---

## 第 1 步：三个分岔问题（先砍掉一半选项）

**Q1. 主人公是无辜被卷入的吗？这个故事的主要内容是不是逃生？**
- 两个都是"是" → **麻烦家伙**
- 否则 → Q2

**Q2. 改变主人公的是"一个人"，还是一个事件／一段过程／一次发现？**
- 是"一个人"（缺了对方就不完整） → **伙伴之情**
- 否则 → Q3

**Q3. 故事的主线是"调查／揭开一个秘密或罪恶"吗？**
- 是 → **推理侦探**
- 否则 → 进入第 2 步

> 这三个问题来自作者自己在后记里给出的判定示范——他就是用"我的主人公是无辜的吗？故事的主要内容是不是逃生？"来区分「麻烦家伙」与「鬼怪屋」的。

---

## 第 2 步：按"故事引擎"归类（三元素填空版）

题材与三元素的对应关系见 SKILL.md 步骤 3。此处给出**填空工作表形式**——把每个问号换成提案里的具体内容，**三个问号都必须填得出，缺一个就不是这个题材**：

| 如果故事引擎是…… | → 题材 | 三元素填空 |
|---|---|---|
| 一个怪物被放进封闭空间，因"罪恶"而来 | **鬼怪屋** | 怪物＝？／房子＝？／罪恶＝？（含无知） |
| 上路去找一样东西，收获的是途中的改变 | **金羊毛** | 道路＝？／团队＝？／奖品＝？（＋路旁的苹果＝？） |
| 愿望成真，然后出事，最后领悟 | **如愿以偿** | 愿望＝？／咒语＋规则＝？／教训＝？ |
| 普通人突遭横祸，拼死求生 | **麻烦家伙** | 无辜主人公＝？／突然的麻烦＝？／生死搏斗＝？ |
| 人生某一段过不去，逃避，最后接受 | **变迁仪式** | 生活的问题＝？／错误的解决方法＝？／真正的解决（接受）＝？ |
| 缺了另一个人就不完整 | **伙伴之情** | 不完整的主人公＝？／伙伴＝？／复杂情况＝？ |
| 揭开一个秘密，自己也卷入罪恶 | **推理侦探** | 侦探＝？／阴谋＝？／黑暗拐点＝？ |
| 被看不起的人在"伟业"里赢了 | **愚者成功** | 愚者＝？／伟业＝？／变化（含换名字）＝？ |
| 加入群体，还是做自己 | **被制度化** | 群体机构＝？／选择＝？／牺牲（三种结局之一）＝？ |
| 一个特殊的人来到小人国，付出代价 | **超级英雄** | 特殊能力／使命＝？／旗鼓相当的敌人＝？／诅咒＝？ |

### 判定不下来时的"反证法"

依次问，**只要有一个答"否"，就排除该类型**：
- 鬼怪屋：有没有一个**超自然力量**的怪物？（如果是普通坏人 → 排除）有没有**封闭空间**？有没有**罪恶**（哪怕是"无知"）？
- 金羊毛：主人公有没有**离开家／离开舒适区**？有没有一个**可画出的成长阶梯**？
- 如愿以偿：有没有一个**明确的愿望**？有没有一个**带规则的魔法**？第三幕主人公会不会**拒绝魔法**？
- 麻烦家伙：主人公**无辜**吗？麻烦是**突然**降临的吗？赌注是**生死**吗？
- 变迁仪式：这是**人生必经阶段**（中年/青春/死亡/分离/成瘾）吗？主人公会不会用**错误的办法**逃避？
- 伙伴之情：主人公的**缺陷**是不是只能由"另一个"补齐？有没有阻断他们的**复杂情况**？
- 推理侦探：有没有一个**待揭开的秘密**？（如果观众一开始就知道真相 → 通常不是）侦探会不会**不变**？
- 愚者成功：主人公是不是**被所有人轻视**？有没有一个他要抗拒的**伟业/新环境**？
- 被制度化：核心冲突是不是"**加入还是不加入**"？有没有**群体**？
- 超级英雄：主人公是不是**真的特殊**（不只是运气好）？有没有**势均力敌的敌人**？有没有**诅咒**？

## 第 3 步：处理混合类型（非常重要）

**规则：列出所有命中的类型 → 判定谁是"主线引擎" → 其余降为副类型叠加。**

判断"主线引擎"的三条标准（按优先级）：
1. **去掉它，故事还成立吗？** 不成立的就是主线。
2. **主人公的主要注意力在哪？** 他大部分时间在做什么——逃命、追查、追求、还是陪伴？
3. **结局兑现的是哪条线的承诺？**

作者自己的案例（《人鬼情未了》）：
- 命中：如愿以偿（超自然）、伙伴之情（爱情："我的生活因另一半而改变"）、推理侦探（帕特里克被陷害致死，复仇前不能见光）。
- 判定：主线是**推理侦探（幻想揭秘）**——因为主线仍是"找出谁是杀害帕特里克的凶手、为什么被害"，与《第六感》同种类型。魔法与爱情都是附着层。

### 常见叠加组合（副类型怎么用）

| 主类型 | 常见副类型 | 叠加效果 |
|---|---|---|
| 鬼怪屋 | 推理侦探 | 怪物＋追查真相（《午夜凶铃》） |
| 金羊毛 | 伙伴之情 | 旅途＋友谊（《一路顺风》《阳光小美女》） |
| 如愿以偿 | 伙伴之情 / 推理侦探 | 魔法＋爱情（《男人百分百》）／魔法＋揭秘（《人鬼情未了》） |
| 麻烦家伙 | 推理侦探 | 逃生＋揭开阴谋（《秃鹰七十二小时》） |
| 变迁仪式 | 被制度化 | 中年危机＋职场（《迷失东京》） |
| 伙伴之情 | 麻烦家伙 | 患难见真情（《泰坦尼克号》） |
| 愚者成功 | 被制度化 | 傻瓜进体制（《律政俏佳人》《阿甘正传》） |
| 超级英雄 | 变迁仪式 | 英雄的成长烦恼（《蜘蛛侠2》的力量消失） |
| 被制度化 | 推理侦探 | 群体＋黑幕（《训练日》《撞车》） |

## 第 4 步：逐拍推演（按类型的固定推演模板）

选定类型后，**按下面的模板逐拍填空**。每个模板都给出该类型在这一拍上"应该发生什么"的默认答案。

### 通用骨架（所有类型共用）
```
开场画面：旧世界的快照（主人公的"静止=死亡"状态是什么？）
主题呈现：谁对他说了哪句他听不懂的话？
铺垫：A 故事全员 + 主人公的缺陷
推动：打破世界的第一击
争论：那句疑问句
第二幕衔接点：他做选择，走进颠倒的世界
B 故事：承载主题的线（通常是人）
游戏：兑现海报承诺
中点：假胜/假败 + 倒计时
坏人逼近：内部分裂 + 外部发威
一无所有：死亡的气息（谁死？死的是什么？）
灵魂黑夜：A/B 故事交汇
第三幕衔接点：B 故事给的新钥匙
结局：第三条路
终场画面：与开场对照，证明变化
```

### 本节比喻性术语速查（下表用到的每一个词都在这里，不用跳文件）

> 这些都是斯奈德自造的"行话"，每个都对应一个具体的可执行动作。完整版见 `04-craft-tools.md`。

| 术语 | 它到底是什么 | 落到剧本上的一个动作 |
|---|---|---|
| **半人** | 曾遭遇怪物、身体残缺或能预知邪恶的幸存者 | 铺垫里出场，负责揭示怪物的神秘、给主人公暗示；**多在"一无所有"（第 75 页）处死去** |
| **玩笑应验** | 铺垫里随口说的一句玩笑话，在中点以最残酷的方式成真 | 在铺垫埋一句看似轻松的台词，在中点让它兑现（《异形》：帕克说"你看上去像死了一样"→ 中点异形从约翰胸腔炸出） |
| **路旁的苹果** | 胜利在望时让计划取消的那个诱惑/事件 | 放在中点前后，使主人公意识到追寻的"金子"不重要（《拯救大兵瑞恩》瑞恩说"不，谢谢！"） |
| **知心人** | 主人公的倾诉对象，对魔法缺乏信心 | 给他一个功能：让主人公把"发生了什么"说出口（也是在说给观众听）；他可能在关键时刻因偏见伤害主人公 |
| **风暴的中心** | 当主人公处在风口浪尖时，唯一与他风雨同舟的那个人 | 不一定是爱情线，但很有效；作用是给叙述和编剧**一个喘息的间隙** |
| **复杂情况** | 阻止两个人在一起的障碍（误解、观念、地理、灾难、社会反对） | 越荒唐越有张力；**它的反讽效果是让两人反而更亲密** |
| **"另一个"** | 使主人公完整的那个伙伴，通常古怪 | **他自身基本不变——他的任务是改变主人公**。规模变体：二人转／三人转（三角恋）／四人转（两对） |
| **黑暗拐点** | 侦探为揭秘而违背自己做人底线的那一刻 | 安排在"一无所有"前后：他意识到自己**已变成罪恶的一部分**，或本就有类似罪恶 |
| **案中案** | 结尾回到出发点，目标甚至指向调查者本人 | 让侦探**重拾第一个案件**并有所发现，同时观众知道真相 |
| **伟业** | 傻瓜主人公要抗拒的那个庞然大物/新环境 | **注意：傻瓜没有雄心大志，"伟业"才是真正的"傻瓜目标"**；"成就"越看不起他，他越能赢 |
| **知情人** | 知道傻瓜真实力量的那个人 | 因嫉妒而受折磨，并试图挫败傻瓜；与傻瓜**成对出现** |
| **换名字** | 主人公获得新称谓 | 愚者成功型中是被迫伪装用的新名字；超级英雄型中是**主动公布**的新名字 |
| **白兰度／天真／公司人** | 「被制度化」的三种角色定位 | 白兰度＝天生反叛者；天真＝最被同情、站在被同化边缘的人；公司人＝体制内的人（常被性无能与疯狂折磨） |
| **柠檬的种子** | 中点埋下的一粒"种子"，之后不断被"挤压" | 埋在中点，随后节奏加快、压力渐增，直到第三幕释放 |
| **崇拜者** | 超级英雄的超级粉丝，从头到尾忠心耿耿 | 给英雄一个"被看见"的镜像；让我们油然起敬 |
| **诅咒** | 超级英雄为能力付出的代价 | **必须有**——根据"不变法则"，一个拥有一切的人不讨人喜欢；诅咒是平衡机制 |
| **选民** | 真正被"选中"的那个人 | 坏人也自认为是选民，但他内心知道自己不是——所以**必须铲除真正的选民**才能获胜 |
| **双重魔法** | 把一种魔法堆在另一种魔法之上 | **陷阱，不要用**——会让故事一团糟，还会产生两套笑话 |
| **第三条路** | 结局的实质 | 既不是开场的老路，也不是第二幕的反路，而是两个世界"综合"出的新路 |

### 类型专属推演提示

| 类型 | 推演时的关键动作 |
|---|---|
| **鬼怪屋** | 先定"罪恶"（这是最容易被漏掉的），再定"房子"的边界（越窄越好），再定怪物的超自然之处。**安排"半人"在铺垫出现、在"一无所有"处死。** 中点通常是"玩笑应验"（铺垫埋一句玩笑话，中点让它以最残酷的方式成真）。 |
| **金羊毛** | 画一条成长阶梯；每一站必须让主人公**有所收获**（不能只为搞笑或大场面）；**在中点前后放"路旁的苹果"**让计划取消；奖品最后要变得不重要。 |
| **如愿以偿** | **先把魔法规则写死**（这是与观众的协议）；排除"双重魔法"；中点通常是"愿望开始反噬"；第三幕必须让主人公**放弃魔法、独自解决**。安排"知心人"。 |
| **麻烦家伙** | 麻烦必须**突然**、主人公必须**无辜**、赌注必须**生死**。用"听众会不会说'伙计，这确实是个麻烦'"来验收。安排"风暴的中心"。中点常是"终于见到敌人"。 |
| **变迁仪式** | 问题＝海报；中段安排一个**看上去很美的错误解决办法**；"一无所有"处让他跌到比开场更糟；"接受"放在灵魂黑夜/第三幕衔接点。给他一个**观众能喝彩的根本利益**。 |
| **伙伴之情** | 开场把两人放在**对立的两端**；设计"复杂情况"（越荒唐越有张力）；决定是二人转/三人转/四人转；**记住：变的是主人公，"另一个"基本不变**。 |
| **推理侦探** | **先写坏人的作案与掩盖手法**（从坏人视角写），再写侦探的追查；安排"黑暗拐点"（侦探违背自己的底线）；考虑"案中案"结构；**在坏蛋逃跑前揭发他**。 |
| **愚者成功** | 定"伟业"（他要抗拒的那个庞然大物）；配"知情人"（嫉妒他的人）；安排"换名字"；让"成就越看不起他，他越能赢"。**主题必须先行**——否则只是段子合集。 |
| **被制度化** | 定群体；在"白兰度/天真/公司人"里给每个主要角色定位；**在中点埋"柠檬的种子"**并让挤压开始；决定三种结局之一（加入／毁灭群体／"自杀"）。 |
| **超级英雄** | 定能力＋**诅咒**（代价，必须有）；造一个**旗鼓相当甚至更强**的敌人（自认为是选民）；安排"崇拜者"；力量展示放在"游戏"；结局常含殉难意象。 |

## 第 5 步：同类片校验

1. 到 `02-ten-genres.md` 找到该类型的**子类型**，挑出 2–3 部同类片。
2. 到 `film-beats/` 查这些片的完整 15 拍拆解（本 skill 已内置 50 部）。
3. 对照问自己：
   - 我的**中点**有没有同类片那么强？
   - 我的**"一无所有"**有没有真正的"死亡气息"？
   - 我的**第三幕衔接点**的新信息是不是来自 B 故事？
   - 我有没有用上该类型的**专属配角**（半人／知心人／风暴的中心／柠檬的种子……）？

---

## 第 6 步：边界复核（不可跳过）

在交付前，对照 `05-limits-and-failure-modes.md` 自查：
- 这个提案是不是**反叙事／非线性／散文化**的？是 → 明确告知用户本方法的局限。
- 这个提案是不是**科幻**？是 → **塌架测试**做了吗？模型 A／模型 B 选对了吗？（见 `06-chinese-hard-scifi.md`；这是唯一需要换结构模型的题材）
- 载体是不是**短片／短剧／剧集**？是 → 用 `01-beat-sheet.md` 第四节的换算，别硬套页码。
- 主人公是不是**女性／少数群体**？是 → 提醒注意原书样本偏向，主动做视角校正。
- 用户要的是不是**艺术片／作者表达**？是 → 说明本方法优化的是观众满意度与可卖性，不等于艺术质量。

## 快速示例：一句提案的完整推演

**提案**："一个外卖骑手在暴雨夜送最后一单，发现收件人是三天前自杀的前女友，而她留下的包裹里有一份能毁掉某家公司的账本。"

1. **信号**：主人公＝骑手（无辜）；引擎＝外部事件（一个包裹）；对抗物＝一家公司＋一个秘密；空间＝城市（路途）；结局＝？
2. **分岔**：Q1 无辜？是，但主要内容不是"逃生"→ 否。Q2 变他的是一个人？否。Q3 主线是揭开秘密？**是** → **推理侦探**。
3. **副类型**：叠加**麻烦家伙**（无辜被卷入、生死搏斗）。
