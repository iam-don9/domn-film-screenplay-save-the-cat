# 中国核心科幻短篇 → 剧本：结构方法论

> **本模块是救猫咪体系的补充，不是替代。**
> **分流提示**：本模块讲的是**短篇小说 → 结构**的适配。如果你要做的是 **≤30 分钟的科幻短片**（尤其需要"想点子、脑洞发散、短片结构、结尾设计"），请改用专项 skill **`domn-film-scifi-short-film`**——它有独立的脑洞引擎（10 原料库 × 12 算子）和按分钟设计的短片结构。本模块的**塌架测试**与**核心科幻三元素**在那边的筛选环节仍会用到。  
> 依据：刘慈欣创作谈与研究论文、王晋康《漫谈核心科幻》、吴岩/丁宁/张冉/张译文关于科幻改编的对谈、《乡村教师》叙事结构分析、中国科幻四大天王与新生代作家研究。  
> 适用：刘慈欣一类的**核心科幻（硬科幻）短篇**改编、原创科幻剧本、科幻 AIGC 短片的故事层设计。

## 一、为什么必须单独一套：与救猫咪的三处根本冲突

刘慈欣一类的核心科幻，恰好命中救猫咪体系**最弱的三处**。这不是"改一改就行"，而是底层预设不同：

| 维度      | 救猫咪（好莱坞商业片）           | 核心科幻短篇                                                                                                                            |
| ------- | --------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| **主人公** | 一个有不完整之处的**个体**，观众代入他 | 刘慈欣原话："**从本质上说，科幻小说的主人公是全人类**……全人类已不仅仅是一家，而是广漠宇宙中孤独地生活在一粒太空灰尘上的一个单一的智慧微生物。"人物可以是**代表性的类型**（他笔下"人物都可以被归类于具有代表性特征的一类人，他们有着显而易见的标志"） |
| **赌注**  | 情感性、个人性（得到/失去/在一起）    | **认知性**——观众的世界观被颠覆。冈恩："科幻小说所描写的灾难，往往是**整个人类种族**的灾难"                                                                               |
| **结尾**  | 变化已发生且**戏剧化、闭合**      | 刘慈欣式结尾常**不闭合**："科幻小说的目的不在于获得确定性，而在于**展现不确定性**"                                                                                    |

**推论**：强行把《乡村教师》《朝闻道》《坍缩》这类作品塞进 15 拍，最常出的三种事故——

1. 为了给主人公"个人缺陷"而**把 idea 降级成背景**；
2. 为了"主题呈现放第 5 页"而**提前泄掉惊奇感**；
3. 为了"结尾闭合"而**把开放性的敬畏改成廉价的希望**。

## 二、理论基石（四条，全部可追溯到原话）

### 1. 王晋康「核心科幻」——最强的可操作定义

> "在这个模糊集的核心是这样一类科幻：它有着突出的'科幻'特质……我把这部分作品称之为**核心科幻**，它就像太极图中的眼。"

**核心科幻三特点**：

1. **宏大、深邃的科学体系本身就是美学因素**——"让科学或大自然扮演**隐形作者**的角色"，这种美可以是哲学理性之美，也可以是技术物化之美。
2. 作品**浸泡在科学精神与科学理性**之中（坎贝尔语）："**以理性和科学的态度描写超现实情节**。"
3. 充分运用科幻独有手法：**独特的科幻构思、自由的时空背景设置、以人类整体为主角**。

> 王晋康判断：刘慈欣、王晋康、何宏伟（何夕）的大部分作品属核心科幻；**韩松的作品大多偏人文，不属于核心科幻**。

### 2. 好的科幻构思的三条判别标准（王晋康）——可直接当验收清单

1. **新颖性**：前无古人的独创性，科学内涵有冲击力，逻辑推理与构思**自洽**。
2. **和故事有内在的逻辑联系**（★最重要）。王晋康给的对照例：
   - ✅ 何夕"分时制"构思（一个女孩基于电脑分时原理"同时"爱上两个男人）——"抽去这个内核，整个故事就塌架了"。
   - ❌ 何夕《伤心者》的微连续构思——"和故事本身没有内在联系，**抽去它，故事丝毫不受影响**"，所以归不到核心科幻。
3. **坚实的科学内核**：能存活于现代科学体系之中，符合公认的科学知识与逻辑方法，**不会被现代科学所证伪**（但不保证能被证实）。符合此条者如《地火》《十字》。

> **塌架测试（本模块的核心工具）**：把你的科幻构思抽掉，故事还成立吗？成立 → 它不是科幻，只是穿着科幻外衣的别的东西。

### 3. 刘慈欣「科学之美」与「认知疏离」

> "科学的美感被禁锢在冷酷的方程式中，普通人需经过巨大的努力，才能窥她的一线光芒。但科学之美一旦展现在人们面前，其对灵魂的震撼和净化的力量是巨大的，某些方面是**传统文学之美难以达到的**。而科幻小说，正是通向科学之美的一座桥梁，它把这种美从方程式中释放出来。"（刘慈欣《混乱中的科幻》）

研究者（韩颖琦、刘延霞）总结其机制：**真实与虚构的危险关系**——读者明知不可能，仍忍不住问"这有可能是真的吗？"，在"认知"与"疏离"之间摇摆，这就是硬科幻的审美核心（对应苏恩文的 **cognitive estrangement / 认知疏离**）。

**刘慈欣自述的创作三阶段**（很有用的自检坐标）：

- **纯科幻阶段**：以科幻构思取胜（《坍缩》《微观尽头》更像阐述科学假说的小说）
- **人与自然阶段**：把人类文明与他种文明置于同样高度（《三体》）
- **社会实验阶段**：以人为中心，用人类文明衡量人类文明（《超新星纪元》）

### 4. 吴岩「科幻改编三点」——立项级判断

> "科幻作品改编中最重要的有如下三点：1. 作品能不能提供一种**视觉奇观**；2. 故事中有没有一种**颠覆人的世界观**的东西；3. 它能不能提供一种**世俗神话**，普通人能不能在当中找到自己，能不能让梦想实现。"

配套：

- **暖科幻 / 冷科幻**：对科幻电影而言软硬之分失去价值，更有用的分类是——看完很感动、在任何语境都被接受的**暖科幻**，与《星际穿越》式的**冷科幻**。
- 制片人丁宁：**中短篇更受制片方欢迎**（"篇幅过长、设定过于宏大的作品暂时不会触碰"）；"**人性是联系虚拟世界和真实空间的桥梁**"，而"**科幻设定是最吸引人的地方**"。
- 作家张冉：改编后"**还是不是科幻**"——完全按编剧意思改完可能就不是科幻了，这是最难协调的。
- 微像文化张译文：每个科幻作品都有一个很强的**科幻核心**，**故事是在这个核心上生长起来的**。

## 三、核心科幻的"三元素"（对照救猫咪的三元素写法）

救猫咪每个题材都有三元素（鬼怪屋＝怪物＋房子＋罪恶）。核心科幻同样有三元素，**缺一即不成立**：

| 元素           | 内容      | 自检问题                                   |
| ------------ | ------- | -------------------------------------- |
| ① **一个科幻构思** | 故事发动机   | 抽掉它故事会不会塌架？（王晋康标准 2）它会不会被现代科学证伪？（标准 3） |
| ② **一个尺度落差** | 认知疏离的来源 | 我把"小"和"大"并置了吗？落差有几级？                   |
| ③ **一个人类命题** | 世俗神话    | 普通人能在当中找到自己吗？（吴岩第 3 点）人性是不是连接虚拟与真实的桥梁？ |

## 四、两套结构模型（按 idea 与人物谁主导来选）

### 模型 A：改造型 —— 沿用救猫咪 15 拍

**适用**：构思可以装进一个具体人物的情感里（何夕式、陈楸帆式、郝景芳式；以及刘慈欣的《带上她的眼睛》这类）。

改造要点只有三条：

1. **把"游戏"段换成"思想实验的展开"**——不是大场面，而是严格按科学逻辑把设定推演到极致。
2. **中点撞击撞的是世界观，不是命运**——让主人公（和观众）发现"原来规律不是我以为的那样"。
3. **B 故事承载的是"人性 vs 规律"的张力**，而不是爱情线。

### 模型 B：认知疏离 5 拍（C5）—— idea 主导时使用

**适用**：主人公是"全人类"、人物是代表性类型、主题关于文明/规律/尺度的刘慈欣式作品（《乡村教师》《朝闻道》《坍缩》《微观尽头》）。

| # | 节拍                     | 功能                  | 写作要点                                     |
| - | ---------------------- | ------------------- | ---------------------------------------- |
| 1 | **常态锚点 Anchor**        | 建一个读者能站住的具体现实       | **越小、越具体、越可信越好**。这是后面所有惊奇感的基准线           |
| 2 | **异常入侵 Anomaly**       | 一个违反已知规律的现象出现       | 读者开始问"这有可能是真的吗？"——**认知疏离启动**。不要解释太多      |
| 3 | **推演展开 Extrapolation** | 严格按科学逻辑把异常推到极致      | 这是"游戏"段的替代物。**快感来自逻辑的彻底性，不是场面**          |
| 4 | **尺度反转 Scale Flip**    | 视角突然拉升或压缩，之前的意义整体翻转 | 对应"中点撞击"，但撞的是世界观。《乡村教师》：传道授业的穷教师 ↔ 拯救太阳系 |
| 5 | **余响落点 Resonance**     | 回到具体的人/物，落在一个意象上    | **不闭合、不说教**。"展现不确定性"，而不是给出确定性            |

### 模型 B 的变体：双线汇流（《乡村教师》模型）

当 idea 需要"两个尺度各讲一条线"时用：

1. **现实主义线**（小尺度：一个人、一个村庄、一段可信的苦难）
2. **科幻线**（大尺度：文明、恒星、规律）
3. **两条线各自推进**，全程靠"**小—大横比**"制造反差张力
4. **汇流点**：两线交汇处浪花迸起，升至高潮（牛顿定律最终挽救太阳系）
5. **落点于希望或敬畏**：用意象呼应收束（《乡村教师》："黑暗与火光"——炉灶柴火、教室烛光、孩子点的香火；结尾烛苗熄灭，化为孩子的星星之火）

**横比（反差）清单——直接可套用的张力发生器**：

- 渺小的个体 ↔ 种族的存亡
- 短暂的寿命 ↔ 亿年的尺度
- 卑微的善 ↔ 宇宙级的后果
- 人类的自以为是 ↔ 规律的冷漠
- 已知的科学 ↔ 被推演到极限后的陌生

## 五、惊奇感（Sense of Wonder）的技术配方

这是核心科幻最不可替代的价值，也是最容易在改编中丢失的东西。六条可操作技法：

1. **让科学或大自然扮演隐形作者**（王晋康）——不是把科学当道具，而是让规律自己推进故事。
2. **以理性和科学的态度描写超现实情节**（坎贝尔）——**语气越冷静，惊奇感越强**。不要惊叹号，不要形容词堆砌。
3. **尺度横比并置**——把"极小"和"极大"放在同一画面/同一场戏里。
4. **命名之美 / 毁灭与美并置**——刘慈欣把毁灭性武器写成"**水滴**"："一滴水银……表面是极其光滑的全反射镜面，银河系在它的表面映成一片流畅的光纹，使得这滴水银看上去纯洁而唯美。"研究者称其"**命名与叙述无一不在宣扬科技的'美'，这份美感表里不一**"。
5. **对偶式主题句**——《乡村教师》最高执政官："宇宙的最不可理解之处在于它是可以理解的。"参议员："宇宙的最可理解之处在于它是不可理解的。"
6. **不闭合**——结尾回答问题的方式是**提出更大的问题**。

**反面清单（会杀死惊奇感）**：

- 提前把所有设定解释清楚（应在"余响"里留白）
- 用角色之口惊叹"太神奇了！"（让画面自己说话）
- 为了煽情把科学逻辑改成巧合
- 把结局解释成道德教训

## 六、五类作家 → 五种故事原型 → 与救猫咪的兼容度

调研出的中国科幻作家谱系（四大天王＋新生代），每种都对应一个可直接迁移的**故事原型**：

| 作家                            | 风格（研究/读者共识）                                                        | 可迁移的原型                            | **与救猫咪的兼容度**                                      |
| ----------------------------- | ------------------------------------------------------------------ | --------------------------------- | ------------------------------------------------- |
| **刘慈欣**                       | 冷峻、宏大、厚重；正统硬科幻；脑洞大、点子多；长短篇质量都稳。"不扯别的，就扯科技"                         | **"规律与文明"原型**：宇宙规律碾压人类意图，人在尺度面前显形 | ⚠️ **低**。主人公是全人类、人物代表性化、结尾不闭合 → 用**模型 B**         |
| **王晋康**                       | 质朴平实、乡土气息；哲理味浓；科学叙事服务于"更宏伟重大的问题"；提出"核心科幻"                          | **"科学伦理困境"原型**：技术突破撞上伦理底线，谁有权决定   | 🟡 **中**。伦理困境常可落到一个人身上 → 可用**模型 A**（麻烦家伙/被制度化的变体） |
| **何夕**                        | 细腻温情柔和；四大天王里**感情戏写得最好**；人文关怀；**短篇远胜长篇**。代表作《六道众生》《伤心者》《我是谁》《人生不相见》 | **"技术时代的人心"原型**：技术改变了关系，但情感仍是赌注   | ✅ **高**。几乎可直接套救猫咪（伙伴之情 / 如愿以偿 / 变迁仪式）             |
| **韩松**                        | 诡谲、阴森、猎奇；"赛博聊斋＋克苏鲁"；恐怖感强。代表作《地铁》《红色海洋》（轨道三部曲）。**王晋康判定其偏人文、不属核心科幻** | **"日常异化/恐怖"原型**：熟悉的日常里渗出不可名状之物    | ✅ **高**。直接对应**鬼怪屋型**（怪物＝异化本身，房子＝日常制度/地铁）          |
| **新生代**（陈楸帆、张冉、江波、宝树、夏笳、郝景芳等） | 陈楸帆短篇厚重；张冉《以太》《大饥之年》；郝景芳《北京折叠》（2016 雨果奖）；整体更偏近未来、社会科幻、技术问题个人化      | **"近未来社会"原型**：技术已落地，冲突发生在具体生活里    | ✅ **高**。与救猫咪兼容度最好，是**短片改编最现实的取材区**                |

**给创作者的实用结论**：

- 想做**惊奇感/宇宙尺度** → 学刘慈欣，用**模型 B**，接受它与救猫咪冲突。
- 想做**可落地、可拍摄、人物立得住的科幻短片** → 从**何夕、韩松、新生代**取材，用**模型 A**。
- 想做**思想密度高但成本可控**的 → 王晋康式伦理困境，单一场景即可成立（最适合低成本/AIGC）。

## 七、科幻提案判定引擎（接在 `03-genre-matching.md` 之后跑）

拿到一个科幻提案，**先跑这个，再决定用哪套**：

**Q1. 塌架测试**：抽掉科幻构思，故事还成立吗？

- 不成立（构思是发动机） → **idea 主导** → 用**模型 B**（认知疏离 5 拍）
- 成立（构思只是背景/装饰） → 它其实是别的类型 → **回到 03 按题材匹配**，用模型 A。
- 介于两者之间 → 用**模型 A + 把"游戏"段换成思想实验展开**。

**Q2. 主人公是谁？**

- 一个具体的人 → 模型 A
- 全人类 / 一个文明 / 一类代表性人物 → 模型 B

**Q3. 赌注是什么？**

- 情感性（失去某人/得不到某物） → 模型 A
- 认知性（世界观被颠覆/文明存续/规律显形） → 模型 B

**Q4. 尺度落差有几级？** 少于两级 → 惊奇感不足，考虑加横比。

## 八、改编检查清单（交付前逐条过）

- [ ] **吴岩三点**：①有视觉奇观？②有颠覆世界观的东西？③有世俗神话（普通人能找到自己）？
- [ ] **张冉之问**：改完**还是不是科幻**？
- [ ] **张译文**：故事是不是**在科幻核心上生长**出来的（而不是核心外挂）？
- [ ] **塌架测试**：抽掉构思故事会塌吗？
- [ ] **丁宁**：篇幅是**中短篇**吗？（设定过于宏大的先别碰）；人性桥梁搭好了吗？
- [ ] **暖/冷取向**已明确告知用户：要暖（感动、普适）还是冷（《星际穿越》式、理性崇高）？
- [ ] 惊奇感六配方至少用到 **2 条**；反面清单一项都没犯。
- [ ] 若是**模型 B**：结尾是否留有不确定性？有没有被强行改成说教？

## 九、边界与警示

1. **本模块不适用于**：太空歌剧、奇幻、赛博朋克动作片等**类型片外壳**（它们应走救猫咪主线）；也不适用于科幻只是美术风格的作品。
2. **核心科幻的受众门槛是真实存在的**。王晋康自己也承认："能够敏锐感受'科学本身的震撼力'的读者常常是少数"，核心科幻的畅销"主要得益于故事性等文学元素"。做短片时要**在惊奇感与可读性之间主动取舍**。
3. **科学准确性与戏剧性的冲突无法消除**。正确做法不是牺牲逻辑，而是**把冲突本身写成戏**（王晋康：核心科幻"更宜于表达作者的人文思考，表现科技对人性的异化"）。
4. **不要为了"人物弧线"牺牲 idea**。刘慈欣的人物本就是"代表性类型"，硬给他加个人缺陷会稀释宏大感；反过来，把宏大感硬塞进个人情感也会变成廉价煽情。**先选模型，再写人物。**
5. **短片化注意**：核心科幻短篇最适合 5–15 分钟（可容下 C5 五拍）；1–3 分钟则只能保留 **Anchor + Scale Flip + Resonance** 三拍，且必须用一个视觉意象承担全部惊奇感。
