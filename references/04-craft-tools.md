# 编剧术语、技巧库与作者铁律

> 全部出自《救猫咪Ⅱ——经典电影剧本探秘》。分三部分：① 通用术语（作者自创）② 结构装置 ③ 题材专属配角与手法 ④ 作者铁律（警句式判断）

---

## 一、通用术语（作者在"最后几句"中集中定义）

| 术语 | 原书定义 | 怎么用 |
|---|---|---|
| **救猫咪（Save the Cat）** | 当我们遇见主人公时，他必须做一些让我们喜欢上他的事情。那就救一只猫吧 | 开场 10 页内给主人公一个**低成本、高共情**的动作（救猫、让座、替人遮掩）。**这不只是为了讨喜，更是为了让观众在后面 100 页里继续陪他受苦** |
| **静止 = 死亡（Stasis = Death）** | 静止是主人公旅途开始前的那一刻；我们知道如果他的生活没有变化，他就会"死" | 每一场戏自问：这一场改变了什么？什么都没变 = 这一场可以删 |
| **气氛变得紧张（Stakes are Raised）** | 也称"**中点撞击**"。影片中间发生了一些事，使主人公压力陡增、遇到新麻烦或有"坏消息" | 中点必须有。形式：倒计时出现／赌注抬高／一个秘密曝光／一个假胜利 |
| **教皇在水池里（Pope in the Pool）** | 转移注意力、避免平铺直叙的方法。名称来自一个剧本场景：教皇在梵蒂冈水池里游泳，影片借机向观众交代乏味的细节 | ** exposition（说明性信息）必须裹在一个反常、有画面感的动作里** |
| **助推火箭（Booster Rocket）** | 影片快结束时出现的一个新角色，把影片推向最后高潮 | 例：《小鬼当家》的约翰·坎迪、《婚礼傲客》的威尔·法瑞尔。用在第三幕衔接点前后 |
| **一个瘸子和一个蒙眼客（A Limp and an Eyepatch）** | 当角色缺少鲜明特点时，这两样可充当独一无二的怪癖或习惯 | 给配角**一个可表演的、外在的识别标记**，让观众一眼记住（《疯狂躲避球》里真戴眼罩的"海盗"史蒂夫） |
| **原始（Primal）** | 作者最爱的词，是促成好故事的动力。检验方法：**一个山顶洞人能理解这个故事吗？** | 写任何动机、赌注、恐惧之前，用它过一遍 |

## 二、结构装置（在 50 部拆解中反复出现）

| 装置 | 说明 | 例子 |
|---|---|---|
| **A 故事 / B 故事交叉点** | 中点、一无所有、灵魂黑夜或第三幕衔接点，通常是两条线的交汇处 | 《异形》中点雷普利找阿休求解释；《黑客帝国》第三幕衔接点选择营救莫菲斯 |
| **虚假的胜利** | 中点形态之一：一切似乎赢了，其实是幻觉 | 《愤怒的公牛》49 分钟没人愿与他对战；《蜘蛛侠2》救火（仍有一人葬身火海） |
| **虚假的失败 / 暂时的失败** | 中点形态之二 | 《大人物波拿巴》中点跳舞；《蜘蛛侠2》"我不再是蜘蛛侠" |
| **死亡的气息** | "一无所有"处必须出现的气息——**有人必须在这里死亡**（可以是象征性的） | 《致命的吸引力》兔子被扔进沸水；《十一罗汉》卡尔的心脏病（后被揭示是计划的一部分） |
| **转弯、转弯、转弯** | 第二幕的情节不能一直向前，必须有变化和加强 | 《异形》怪物不断变化形态；《秃鹰七十二小时》的连续反转 |
| **烟幕弹（red herring）** | 误导性线索 | 《惊声尖叫》学生装扮成杀手、校长寻求刺激 |
| **影片许下的诺言** | 海报/预告承诺给观众的东西，必须在"游戏"段兑现 | 《致命武器》铐在一起跳楼；《当哈利碰见萨丽》朋友式相处 |
| **颠倒的世界 / 反主题世界** | 第二幕是与第一幕"主题世界"相反的镜像空间 | 《狮子王》"Hakuna Matata"的无忧生活 |
| **案中案** | 结尾回到出发点，目标甚至指向调查者本人 | 《漫长的告别》 |
| **倒叙（闪回）结构** | 在铺垫之后不可避免地使用，用来交代"罪恶" | 《电锯惊魂》 |
| **计划败露** | 第三幕常见情节：主人公的计划在实施前被发现，导致被抓、只得另求出路 | 《角斗士》 |
| **结尾保留续集接口** | 用一个未闭合的装置保证续集 | 《午夜凶铃》复制录像带；《电锯惊魂》"游戏结束" |
| **"柠檬的种子"** | 影片过半（中点）埋下一粒种子，随后"挤压"开始——节奏加快、压力渐增，直到第三幕释放 | 《训练日》；"每部剧本里都以不同方式存放一粒'柠檬种子'" |
| **开场/终场画面呼应** | 开场是故事开始前的快照，终场证明变化已发生 | 《阿甘正传》羽毛；《角斗士》麦穗与梦境；《黑客帝国》电脑屏幕与电话 |

## 三、题材专属配角与手法（详解）

配角名与题材的对应速查见 SKILL.md。此处补充每个配角的**做法**与**落地动作**：

| 题材 | 专属配角／装置 | 一句话做法 |
|---|---|---|
| 鬼怪屋 | **"半人"** | 幸存者 + 残缺/能预知邪恶 + 揭示怪物 + 在"一无所有"处死 |
|  | **"玩笑应验"** | 铺垫里随口说的一句玩笑，在中点以最残酷的方式成真（《异形》："你看上去像死了一样"→腹中炸出） |
| 金羊毛 | **"路旁的苹果"** | 胜利在望时让计划取消，使主人公意识到金子不重要 |
|  | **团队闪亮出场** | 铺垫里让每个成员简洁经济地展示本领；给不完美的外在标记 |
| 如愿以偿 | **"知心人"** | 倾诉对象；对魔法缺乏信心；可能在关键时刻伤害主人公 |
|  | **魔法规则** | 必须写死并坚持；警惕"双重魔法" |
| 麻烦家伙 | **"风暴的中心"** | 唯一相信主人公的人，给叙述与编剧一个间隙 |
| 变迁仪式 | **错误的解决方法** | 看上去很美，实质是躲避不可避免之事 |
| 伙伴之情 | **"另一个"** | 古怪、自身不变、任务是改变主人公 |
|  | **"复杂情况"** | 阻止两人在一起的障碍（误解/观念/地理/灾难/社会反对）；越荒唐越有张力，**反讽地让两人更亲密** |
|  | **二人转 / 三人转 / 四人转** | 决定几条感情线的规模 |
| 推理侦探 | **"案中案"** + **"黑暗拐点"** | 从坏人视角先写；侦探违背自己的底线 |
| 愚者成功 | **"伟业"** | 傻瓜要抗拒的那个庞然大物／新环境。**傻瓜没有雄心大志——"伟业"才是真正的"傻瓜目标"** |
|  | **"知情人"** + **换名字** | 知情人因嫉妒受折磨并试图挫败傻瓜；换名字＝被迫伪装用的新称谓 |
| 被制度化 | **白兰度 / 天真 / 公司人** | 三件套；公司人常被性无能和神智疯狂折磨 |
|  | **"柠檬的种子"** | 中点埋下，之后不断"挤压"（节奏加快、压力渐增），直到第三幕释放 |
| 超级英雄 | **"崇拜者"** + **诅咒** + **势均力敌的敌人** | 崇拜者从头忠心耿耿；诅咒平衡能力以免观众嫉妒 |
|  | **"选民"** | 真正被选中的人。坏人自认为是选民但内心知道自己不是——所以必须铲除真正的选民 |
| 通用 | **"第三条路"** | 结局的实质：既不是开场的老路，也不是第二幕的反路，而是两个世界"综合"出的新路 |

## 四、跨题材的写作手法（作者在分析中零星给出的实用招）

**人物**
- 让观众同情人物有两种办法：**一是这个人物是行善的好人，二是这个好人受到欺负**。（《律政俏佳人》铺垫技巧）
- 塑造主人公：选择经验丰富的老演员并让他**一改往日角色定位**，能给角色期待带来最大冲击（如让梅尔·吉布森演女性杀手）。
- **用对话揭示角色性格**：《阿甘正传》的布巴"每次说话总离不开谈论虾"。
- **给角色取有纪念意义的名字**（《致命武器》的迈克尔·亨塞克）。
- **"推动"型配角**：设置一个次要角色去推动主人公回归正轨（《断背山》的小艾玛）。

**信息交代**
- **"教皇在水池里"**：把说明性信息裹进一个有反差的动作里。
- **行业知识细节**：为群体题材学习特种行业知识，近距离呈现行业工作状态（《空中塞车》《铁皮人》《不羁夜》）。
- 在不远的将来安排"**一件大事**"，可以让拥有魔法显得格外不方便。

**节奏**
- **劫盗片"游戏"的三大基点**：展现抢劫计划 / 展现计划如何受挫 / 向观众保留一点行动细节。
- **多线群像必须强化节奏**，只展现与主题最相关的元素——这是"群体"影片震撼力的来源。
- **"坏人逼近"是任何剧本最难写的一部分**（天然容易慢）；办法是内部与外部同时加压。
- 浪漫喜剧的"游戏"可以走**六步结构**：拒绝→害怕→分享→检验→拒绝→运用魔法。

**主题与视觉**
- **主题先行**：《窈窿淑男》"内容搞笑有意义，但在形成明确主题前不是成功的故事"——主题使所有情节、片段、笑话有了意义。
- **标志性颜色 / 视觉母题**：《律政俏佳人》的粉红色是"出水之鱼"傻瓜胜利的标志。
- **宗教／神话意象**：超级英雄片的殉难与十字架意象；《愤怒的公牛》的动物意象与宗教意象（主题：失去优雅）。
- **老酒装新瓶**：老套的故事增加新情节，使影片有新意（《断背山》）。

## 五、作者铁律（警句式判断，可直接用作自检清单）

**关于故事本质**
- 你的剧本永远都不会是原创的题材。编剧工作的本质就是**把老套的故事讲出新鲜感**。
- 题材的相同元素像**音叉**一样会产生共鸣，这种共鸣的根源是人类具有相同的基因。
- 所有故事都和**变化**有关，这种变化最好具有戏剧性。
- 故事都讲述了一个生活的道理，这就是为什么它们总是被重复。

**关于结构**
- 一个令人满意的故事离不开结构（即便是"自由形式"的影片）。
- **当你改变这种或任何故事的结构时，你等于是将自己置于险境。**（难点在填补留下的空白）
- 开场画面与终场画面相呼应——**变化已经发生**。
- 根据"**一无所有**"的原则，主人公要比"影片开始时还要糟糕"。

**关于类型**
- 怪物不恐怖 = 电影不刺激。
- 没有"罪恶"的影片，就不完全是"鬼怪屋"型。
- 主人公是团队的核心，通常是个"**无聊**"的家伙。
- 每个路标的出现都有其特定的理由和意义，而不是仅仅因为它"滑稽"或是大场面。
- 旅途的故事是我们箭袋里拥有的最古老的一种，但也是**最难讲好**的一种。
- **当心你的愿望！**
- 如果我们没有遵守魔法规则，就等于**撕毁了与观众的"协议"**，这样就会失去观众。
- "**双重魔法**"并不能让影片变得双倍的好。
- 惹火上身并不是「麻烦家伙」的内容——**主题是求生，而不是因罪恶而受到惩罚**。
- 听众的反应必须是"**伙计，这确实是个麻烦！！**"，下一句是"**换作是我，我会怎么做？**"
- 只有**违反本能地去拥抱痛苦**才能解决问题。（变迁仪式）
- 隐藏在最后一个小船舱里的不是罪恶，**而是我们自己**。（推理侦探）
- **"侦探"没有变化，变化的是我们。**
- 最后别忘了**在坏蛋逃跑前揭发他**。
- "**成就**"越是看不起他们，他们越是能获得最后的胜利。（愚者成功）
- **要么规则是疯狂的，要么质疑规则的我们是疯狂的。**（被制度化）
- 顺从就等于**失去了人生的果实**。
- 他们的牺牲其实就是"**自杀**"。
- 一个拥有一切的人是不讨人喜欢的——所以超级英雄必须有"诅咒"。（剧本创作的不变法则）

**关于创作者**
- 编剧从事的工作就是**告诉国王他并没有穿着衣服**。
- 所有的编剧都是顽固分子。
- 如果你想"难倒作者"、创造出不在这 10 种题材之内的影片，你趁早省省力气吧。
- 要做到这一点，你必须敢于面对一个真正的挑战：**写完 110 页**。
- 影片成功与否的关键在于**我们喜不喜欢看这部电影**。
- 作者并不是一部好剧本的最佳鉴别者。
- "**不要给我漏掉任何的细节。**"（帕库拉的咒语）
